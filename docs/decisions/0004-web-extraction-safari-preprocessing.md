# 0004 网页正文由 Safari 分享扩展预处理获取

- 日期：2026-11-09
- 状态：已采纳

## 背景
服务器位于海外（ADR 0007）。微信公众号、知乎等常见中文来源存在反爬、登录墙或 JS 渲染，服务端抓取成功率低。

## 决策
- 分享扩展配置 `NSExtensionJavaScriptPreprocessingFile`，在 Safari 中读取已渲染页面的 URL、标题、规范链接、正文（Readability 类提取）及抓取时间，作为 `client_extract` 加工版本随提交上传。
- 服务端抓取作为补充：客户端未提供正文、正文过短，或用户请求重新抓取时执行；保留原方案全部 SSRF 防护。
- 两者都失败时显示状态，允许用户粘贴正文。

## 后果
- 客户端提取的正文是不可信内容：服务端做大小（≤100,000 字符）、编码与 HTML 清洗校验，只作为模型上下文中的资料。
- 引用定位到保存的正文快照，标注来源为"分享时页面快照"。
- 非 Safari App 的分享只得到 URL，走服务端抓取。

## 待验证（S0）

- [ ] 预处理脚本在大页面上的耗时与扩展内存。
