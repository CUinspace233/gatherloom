# 0007 服务器部署在海外/港澳

- 日期：2026-11-09
- 状态：已采纳

## 背景
已有服务器位于海外/港澳。

## 决策
- 对外 HTTPS 域名无需 ICP 备案；Docker Compose + HTTPS 反向代理为唯一公网入口。
- 百炼使用国际站端点（ADR 0001）；DeepSeek 使用其公开 API 端点。
- 国内网页正文主要依赖分享扩展预处理（ADR 0004）。

## 后果
- 中国大陆用户访问 API 可能存在延迟或线路波动：客户端 Outbox 与重试已覆盖，S6 用真机在大陆网络测试上传与问答延迟。
- 邀请用户的资料会发送到 DeepSeek 与阿里云，需在注册时告知数据流向与模型服务商。
